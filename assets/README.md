## Спрайты для окна игрока

Положите PNG (с прозрачностью) в эту папку. Программа подхватит их автоматически.

Рекомендуемые имена файлов:

- `player_steve.png` (или `steve.png`) — спрайт игрока в стиле Minecraft для всех трёх участников
- `player1.png` — левый игрок
- `player2.png` — средний игрок
- `player3.png` — правый игрок (у табло)
- `host.png` или `host_yakubovich.png` — ведущий (справа), PNG; при необходимости уменьшится автоматически
- `audience.png` — (опционально) фон-зрители слева

Рекомендации:
- Формат: **PNG с альфой**
- Размеры (примерно): игроки 300×420, ведущий 420×520 (можно больше — будет масштабировано)
- “Ноги”/низ спрайта желательно оставить на одной линии (проще ровно поставить на сцену)
