# Поле чудес (ПК-версия, 2 окна)

Это локальная игра-викторина в стиле «Поле чудес» для ПК.

- **Окно 1 (Game)**: основная сцена — табло со словом, тройка игроков, барабан.
- **Окно 2 (Control)**: «пульт» ведущего/оператора — настройка вопросов, управление барабаном, лог событий.

## Запуск

Требуется Python 3.10+ (проверено на Python 3.13).

```powershell
python .\main.py
```

## Краткие правила (пересказ)

Ниже — **сжатый пересказ** распространённых правил/механик телеверсии (в разных сезонах детали могли отличаться).

- **Структура**: обычно 3 тура (3 тройки игроков) → финал (победители туров) → иногда «суперигра».
- **Ход игрока**:
  - игрок крутит барабан;
  - если выпали **очки**, игрок называет **букву**;
  - если буква есть в слове, она открывается на табло, игрок получает очки (как правило, за каждое вхождение буквы) и ход продолжается;
  - если буквы нет — ход переходит следующему игроку.
  - в любой момент игрок может попытаться назвать **слово целиком**.
- **Сектора барабана** (типичные):
  - **очки** (разные значения),
  - **0 / переход хода**,
  - **банкрот** (обнуление очков игрока за текущий тур),
  - **приз** (логика зависит от версии: приз/выбор/продолжение игры),
  - иногда **x2/x3**, **+1 буква** и т.п.
- **Переход между тройками**:
  - в основной сцене очки и имена новой тройки начинаются с нуля,
  - на пульте удобно хранить историю результатов всех троек (в этой реализации так и задумано).

Источники для ориентира (на случай сверки терминов):
- `https://polechudes.tv/rules.php`
- `https://ru.wikipedia.org/wiki/Поле_чудес`

## Примечания по реализации

- Управление буквами сделано **экранной клавиатурой** (кнопки), а не вводом с HID-клавиатуры.
- В пульте есть «терминал»-лог, который можно сворачивать и очищать.
- Визуал «как в оригинале» и барабан в перспективе (цилиндр/эллипс) реализуются Canvas-анимацией.
